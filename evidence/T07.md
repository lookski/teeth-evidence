# T07. 牙周炎与糖尿病: 双向关系与血糖获益

> 层级: [← 总结 README](../README.md) · [维度速览 00-total](../topics/00-total.md) · 本页 `T07`

## 一句话结论

糖尿病使牙周炎易感性约升 3 倍; 反过来, 重度牙周炎使糖尿病患者的心肾死亡风险升至 3 倍;
治疗牙周炎可使 HbA1c 下降约 0.4% — 与加一种弱口服降糖药相当。

## 研究设计与人群

- 设计: Diabetologia 权威综述 (双向关系框架) + Diabetes Care meta (5 项 RCT, 371 名 2 型糖尿病患者,
  随访 3-9 个月)
- 暴露/干预: 牙周炎状态 / 牙周治疗
- 终点: 牙周炎风险, 血糖控制 (HbA1c / ΔA1C), 微血管与大血管并发症

## 关键数字 (摘自摘要原文)

| 项目 | 数字 |
|---|---|
| 糖尿病 → 牙周炎易感性 | 增加约 3 倍 (increased by approximately threefold) |
| 糖尿病+重度牙周炎 → 大量白蛋白尿 | 2 倍 |
| 糖尿病+重度牙周炎 → 终末期肾病 | 3 倍 |
| 糖尿病+重度牙周炎 → 心肾死亡 | 3 倍 |
| 牙周治疗 → HbA1c | 下降约 0.4% |
| meta: ΔA1C 加权差值 | **-0.40% (95% CI -0.77 到 -0.04, P=0.03)**, 异质性 59.5% |

## 剂量反应与可执行解读

- 血糖越高牙周炎越重 (degree of hyperglycaemia 与 severity 关联), 双向放大
- 可执行: 糖尿病患者把牙周检查列入年度常规; 牙周治疗是"顺带降糖"的合法操作
- 0.4% 的降幅虽小, 但不增加药物负担

## 证据强度与局限性

- 优势: 双向关系概念清晰, meta 聚焦 RCT
- 局限: 纳入试验少 (5 项), 随访短 (3-9 个月), 异质性偏高

## 与其他证据的一致性

- 与 T01-T06 (牙周-死亡/血压) 同属"牙周炎症全身化"证据链
- 与 T11 (吸烟-牙周 meta) 一起构成牙周病两大可干预系统风险因素
