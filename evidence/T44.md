# T44. HPV 与口咽癌: 病因范式转移, 与烟草相关癌分流

> 层级: [← 总结 README](../README.md) · [维度速览 00-total](../topics/00-total.md) · 本页 `T44`

## 一句话结论

HPV 相关口咽癌已成为独立流行病学实体: NRGS/De-ESCALaTE 两大降级 RCT 证实其放疗敏感性
不同, p16 阳性患者可减毒治疗; 流行病学上 HPV+ 口咽癌发病率上升而烟草相关口咽癌下降 —
口腔健康的癌症版图正从"烟酒槟榔"单轴变为"烟酒槟榔 + HPV 感染"双轴。

## 研究设计与人群

- 设计一: NRG Oncology RTOG 1016 (III 期非劣效 RCT, HPV+ 口咽癌, 西妥昔单抗 vs 顺铂放化疗)
- 设计二: De-ESCALaTE HPV (III 期开放标签 RCT, 低危 HPV+ 口咽癌, 顺铂 vs 西妥昔单抗)
- 设计三: 流行病学综述 (HPV+ 口咽癌的分子生物学与临床管理)

## 关键数字 (摘自摘要原文)

| 项目 | 数字 |
|---|---|
| RTOG 1016 | 西妥昔单抗组劣效于顺铂 (非劣效不成立; HPV+ 患者顺铂仍是标准) |
| De-ESCALaTE | 西妥昔单抗组两年内死亡风险更高 (顺铂减量方案失败) |
| 病因范式 | HPV+ 与烟草相关口咽癌是生物学不同的两个疾病, 预后不同 |
| 临床意义 | p16/HPV 检测是口咽癌标准分期依据 (ICON-S 分期, Lancet Oncol) |

## 剂量反应与可执行解读

- 对"护牙"的含义: 口咽癌双轴时代, 预防动作增加一项 — HPV 疫苗 (男女均接种, 预防口咽癌
  证据在积累) + 戒烟限酒 (另一轴)
- 口腔科视角: 扁桃体/舌根原发灶常以颈部转移包块首发 → 不明颈部包块查口咽 + HPV
- 口腔卫生与 HPV 感染持续性的关联在研究中 (口腔卫生差→HPV 清除慢), 属机制合理待确证

## 证据强度与局限性

- 优势: 两大 III 期 RCT + 权威综述; 改变了临床分期与治疗标准
- 局限: 本条聚焦治疗降级失败 (顺铂仍是标准), 非"如何预防"; 疫苗对已感染成人无治疗作用

## 与其他证据的一致性

- 与 T32/T33 (槟榔/牙周炎-口腔癌) 构成口腔癌三因格局: 化学致癌物 (烟酒槟榔) +
  慢性炎症 (牙周) + 病毒 (HPV)
- 与 T30 (COVID) 同属"口腔的全身病毒叙事"
