# T34. GERD 与牙侵蚀: 内源性酸是"氟防不住"的第二来源

> 层级: [← 总结 README](../README.md) · [维度速览 00-total](../topics/00-total.md) · 本页 `T34`

## 一句话结论

胃食管反流病 (GERD) 患者牙侵蚀显著更重 (TWI 均差 0.66, P=0.004), 机制是胃酸+胃蛋白酶
直接破坏釉质-保护膜 (睡眠仰卧加剧, 唾液减少) — 不明原因的牙侵蚀 (尤其舌腭面)
应想到内源性酸, 处理路径是内科转诊而非单纯换牙膏。

## 研究设计与人群

- 设计一: 横断面 (20 名连续转诊消化科的成人; 内镜+24h pH 测压判定 GERD, TWI 量化牙侵蚀)
- 设计二: 综述整合 (动物+人体证据; 唾液流率与吞咽功能下降的 GERD 患者口腔症状更重)

## 关键数字 (摘自摘要原文)

| 项目 | 数字 |
|---|---|
| GERD vs 非 GERD: TWI 总分均差 | 0.6554 (P=0.004) |
| 分布特征 | 除下颌前牙区外所有象限 GERD 组更高 (符合反流接触面) |
| 机制 | 胃酸置换唾液; 胃蛋白酶去除获得性保护膜; 睡眠仰卧促进近端迁移 |

## 剂量反应与可执行解读

- 牙侵蚀两大来源: 外源 (酸性饮料, T27) + 内源 (反流); 氟化物对两者都只是"减慢", 防不住
- 可执行: 舌面/腭面光泽消失+杯状凹陷+充填物"浮起" → 问反流/烧心史; 不明侵蚀转消化内科
  (24h pH 监测/内镜), 先治反流再修复
- 睡前 3 小时不进食 + 抬高床头 = 同时护牙和护食管的低风险手段

## 证据强度与局限性

- 优势: 客观暴露判定 (内镜+pH 监测) 而非自报; 机制链完整
- 局限: 样本小 (20 人); 无纵向干预数据 (抑酸治疗后牙面稳定性的 RCT 缺)

## 与其他证据的一致性

- 与 T27 (酸蚀外源途径) 合并构成"酸"这条线; 与 T15 (氟的边界) 呼应
- 与 T16 (中国流调) 衔接: 中国 GERD 患病率上升, 牙侵蚀潜在负担同步上升
