# T43. 智齿冠周炎: 垂直位+部分软组织覆盖=高危形态, 影响进食睡眠

> 层级: [← 总结 README](../README.md) · [维度速览 00-total](../topics/00-total.md) · 本页 `T43`

## 一句话结论

102 例急性冠周炎分析: 最高危形态是垂直阻生 (51%) + 75% 软组织覆盖 (47%) + 萌出至邻牙
咬合平面 (占 57%); 冠周炎一周内 28% 患者经历重度疼痛, 23% 进食困难 —
年轻成人"智齿区反复肿痛"有明确形态学预测因素, 处理有据可依。

## 研究设计与人群

- 设计一: 横断面 (102 名急性冠周炎患者, 均龄 23.4; 临床+影像分析阻生角度/软组织覆盖/
  萌出水平/对颌牙干扰)
- 设计二: 生活质量研究 (57 名症状性冠周炎; 一周疼痛量表 + OHIP-14)

## 关键数字 (摘自摘要原文)

| 项目 | 数字 |
|---|---|
| 阻生角度分布 | 垂直 51%, 近中 25%, 远中 21%, 水平 3% |
| 软组织覆盖 | 部分覆盖 (尤其 75%) 远多于完全覆盖 (47% vs 更少) |
| 萌出水平 | 57% 病例与邻牙咬合平面同高 (P<0.000) |
| 对颌牙干扰 | 无显著影响 (P=0.075) |
| 高危形态结论 | 垂直位+接近咬合平面+软组织瓣覆盖 = 冠周炎高危, 优先预防性处理 |
| 疼痛 (一周最重) | 重度 28%, 中度 40% |
| 功能影响 | 进食困难 23%, 咀嚼 19%, 张口 6% (重度) |
| OHIP-14 中位分 | 11/56; 疼痛维度最突出 |

## 剂量反应与可执行解读

- 机制: 接近咬合平面的垂直阻生牙+软组织瓣 = 咀嚼创伤瓣+菌斑滞留袋, 正是冠周炎的解剖温床
- 可执行: 反复冠周炎 (≥2 次) 或高危形态 → 评估拔除时机 (年轻恢复快);
  急性期先冲洗上药消炎再择期手术; 发作期用温盐水+软食
- 与 T26 (阻生智齿邻牙损伤) 合并决策: 智齿拔与不拔, 看 (1) 冠周炎史 (2) 邻牙风险 (3) 形态

## 证据强度与局限性

- 优势: 形态学风险因素具体可操作 (影像即可评估); QoL 有量化
- 局限: 单中心横断面; 无预防性拔牙 vs 观察的长期 RCT (该问题证据面仍争议)

## 与其他证据的一致性

- 与 T26 (智齿与邻牙龋/根吸收) 是同一决策的两半
- 与 T17 (GBD 负担) 连接: 口腔疼痛负担的年轻成人段主要由第三磨牙贡献
