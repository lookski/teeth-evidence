# T20. 牙线: Cochrane 说"证据弱", 但邻面清洁仍是方案核心

> 层级: [← 总结 README](../README.md) · [维度速览 00-total](../topics/00-total.md) · 本页 `T20`

## 一句话结论

Cochrane (12 项试验 1,083 人): 牙线+刷牙在 1/3/6 个月降低牙龈炎 (6 个月 SMD -0.72) 且随时间增强,
但证据质量弱, 无龋齿终点数据; 专业牙线在儿童使邻间龋降 40%, 自行使用无效 —
"方法正确与否"比"用不用牙线"更重要。

## 研究设计与人群

- 设计一: Cochrane SR (刷牙±牙线, RCT, 主要终点菌斑与牙龈炎)
- 设计二: 邻间龋系统综述 (6 项试验, 808 名 4-13 岁儿童)

## 关键数字 (摘自摘要原文)

| 项目 | 数字 |
|---|---|
| 牙龈炎 1 个月 | SMD -0.36 (-0.66 到 -0.05) |
| 牙龈炎 3 个月 | SMD -0.41 (-0.68 到 -0.14) |
| 牙龈炎 6 个月 | SMD -0.72 (-1.09 到 -0.35) |
| 菌斑 | 弱且不可靠的小幅下降 |
| 龋齿终点 | 无试验报告 |
| 专业牙线 (儿童, 1.7 年) | 邻间龋 RR 0.60 (0.48-0.76), 降 40% |
| 每 3 个月一次专业牙线 | RR 0.93 (0.73-1.19) (无效) |
| 青少年自用 2 年 | RR 1.01 (0.85-1.20) (无效) |

## 剂量反应与可执行解读

- 强度随使用时间上升 (0.36→0.41→0.72): 牙线的效果是"练出来的"
- 可执行: 牙缝刷 (间隙刷) 对牙周患者优于牙线 (专业共识, 未在本条展开); 牙线要求 C 形包绕刮面, 不会用=白用
- 无龋齿终点 + 自用无效 ≠ 牙线没用, 是"自用牙线普遍用不对"

## 证据强度与局限性

- 优势: Cochrane 随机证据 + 儿童专业操作剂量对比, 信息量大
- 局限: 试验小 (582/501 人), 高偏倚比例 (5/12 高风险); 结论自评"weak, very unreliable"

## 与其他证据的一致性

- 与 T18 (Axelsson 程序把牙缝工具列为标准配置) 人群面一致
- 与 T09 (行为 SR: 刷+缝清洁 HR 0.54) 方向一致
