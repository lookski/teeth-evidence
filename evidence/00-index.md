# 证据条目索引 (Teeth Evidence Index)

> 本目录是 README.md 主报告的逐项分析层。README 只保留结论, 每条证据的详细分析
> (研究设计, 人群, 剂量反应, 局限性, 与其他证据的一致性) 放在这里, 一个条目一个文件。
> 各条目关键数字均摘自论文摘要原文 (Europe PMC), 摘要截断处的数字标注"见原文"。

## 编号规则

- `T01`-`T03`: 牙周病与死亡 / 心血管共识
- `T04`-`T07`: 因果与并发症 (高血压 MR+RCT / 观察 meta / 糖尿病双向)
- `T08`-`T10`: 干预与护理 (洗牙 / 口腔卫生实践 / 老年肺炎)
- `T11`-`T13`: 风险与机制 (吸烟 / 痴呆与病原入脑 / 咀嚼与脑)
- `T14`-`T15`: 工具与氟 (电动牙刷 / 含氟牙膏与水氟)
- `T16`-`T18`: 负担与行为天花板 (中国流调 / GBD / 30 年菌斑程序)
- `T19`-`T21`: 饮食与行为 (糖 / 牙线 / 无糖口香糖)
- `T22`-`T26`: 咬合力与牙稳固辨析 (咬合创伤 / 牙动度 / 磨牙过载 / 颈部缺损 / 智齿)
- `T27`: 酸蚀
- `T28`: 遗传度与个体差异
- `T29`: 叩齿/咬硬物专项辨析 (负结果 + 风险面)
- `T30`: COVID-19 重症佐证
- `T31`: 牙周病与早产 (重要负结果: 治疗 RCT 不降早产)
- `T32`-`T33`: 口腔癌 (槟榔 1 类致癌物 / 牙周炎与 OSCC)
- `T34`: GERD 内源性酸与牙侵蚀
- `T35`: 牙周炎与 ED (台湾全人群 OR 3.35 + RCT)
- `T36`: 失牙与营养 (纵向 + 义齿 RCT)
- `T37`: 种植体周炎 (患病率 + 维护)
- `T38`: 磨牙症管理 (咬合垫定位)
- `T39`: 药物性口干 (56 种物质清单)
- `T40`: 刷牙过猛与牙龋退缩
- `T41`: 木糖醇定量 (40 个月队列 RR 0.27)
- `T42`: 牙科恐惧的恶性循环
- `T43`: 智齿冠周炎 (高危形态 + QoL)
- `T44`: HPV 与口咽癌 (双轴病因范式)
- `T45`-`T55` (第三轮扩展, 英文条目): 预防程序 (窝沟封闭 T45 / 涂氟 T46 / 正畸白斑 T47),
  新全身关联 (电子烟 T48 / 类风湿 T50 / 慢性肾病 T51 / 肥胖 T52), 口腔衰弱与舌压 (T53),
  牙科 X 线剂量 (T54), 冲牙器 (T55)
