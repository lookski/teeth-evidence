# T01. 牙周病/无牙与死亡风险 (57 项研究 meta)

> 层级: [← 总结 README](../README.md) · [维度速览 00-total](../topics/00-total.md) · 本页 `T01`

## 一句话结论

57 项队列 48 个队列 571 万人: 牙周病患者全因死亡 RR 1.46 (1.15-1.85), 无牙者 1.66 (1.46-1.88);
冠心病死亡 2.58 / 脑血管死亡 3.11 (牙周炎), 无牙者更高达 2.98 / 3.18 —
牙齿支撑结构的炎症是全身性风险标记, 不是孤立的"口腔小毛病"。

## 研究设计与人群

- 设计: 系统综述 + 随机效应 meta 分析 (PROSPERO CRD42018100095)
- 纳入: 57 项队列研究, 48 个独立队列, 合计 571 万人
- 暴露: 牙周炎; 及其终末结局无牙 (edentulism)
- 终点: 全因死亡与病因别死亡 (心血管/癌症/冠心病/脑血管/肺炎)

## 关键数字 (摘自摘要原文)

| 结局 | 牙周炎 RR (95% CI) | 无牙 RR (95% CI) |
|---|---|---|
| 全因死亡 | 1.46 (1.15-1.85) | 1.66 (1.46-1.88) |
| 心血管病死亡 | 1.47 (1.14-1.90) | 2.03 (1.50-2.74) |
| 癌症死亡 | 1.38 (1.24-1.53) | 1.55 (1.24-1.94) |
| 冠心病死亡 | 2.58 (2.20-3.03) | 2.98 (2.43-3.65) |
| 脑血管病死亡 | 3.11 (2.42-3.98) | 3.18 (2.24-4.51) |
| 肺炎死亡 | 0.98 (0.69-1.38) | 1.72 (1.07-2.78) |

## 剂量反应与可执行解读

- 梯度方向: 从牙周炎 (炎症仍在) 到无牙 (结构已毁), 风险逐级升高 — 提示"留住牙齿"比"装假牙"更有意义
- 可执行: 牙周炎可防可治 (见 T08 专业洁治, T12 戒烟), 是这一链条里唯一可干预的环节
- 注意: 无牙与死亡的关联含大量残余混杂 (口腔差的人往往整体健康行为差, 收入低)

## 证据强度与局限性

- 优势: 纳入研究多, 样本 571 万, 随机效应模型合并
- 局限: 观察性 meta, 无法排除混杂与反向因果 (系统病导致牙周恶化); 牙周炎判定标准各研究不一

## 与其他证据的一致性

- 与 T02 (中国 CKB 刷牙队列) 方向一致: 口腔卫生差 → 全因死亡 HR 1.25
- 与 T03 (牙周炎-高血压共识) 机制叙述互洽: 炎症入血
