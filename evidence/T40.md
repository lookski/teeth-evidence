# T40. 刷牙过猛与牙龈退缩: 硬刷+横刷+高频 = 退缩三要素

> 层级: [← 总结 README](../README.md) · [维度速览 00-total](../topics/00-total.md) · 本页 `T40`

## 一句话结论

硬毛牙刷使用者退缩面比例翻倍 (9.4% vs 4.7%) 且随刷牙频率上升 (不用硬刷者无此效应);
SR 确认最常见相关因素 = 刷牙频率 + 横向拉锯式刷法 + 刷毛硬度 + 时长;
电动 vs 手动 3 年 RCT: 对已有退缩两者均使退缩减轻, 无显著差异 —
"认真刷牙"本身可以伤牙, 方法比力度重要。

## 研究设计与人群

- 设计一: 横断面 (182 名 18-65 岁; 82 硬刷史 vs 77 无; 退缩面比例回归)
- 设计二: SR (创伤性刷牙 vs 正常刷牙; 1 meta + 13 横断面; 12 个月手动 vs 电动)
- 设计三: 3 年单盲 RCT (109 名已有退缩者; 电动 vs ADA 参考手动刷, 每天 2 次 2 分钟)

## 关键数字 (摘自摘要原文)

| 项目 | 数字 |
|---|---|
| 硬刷史: 退缩面比例 | 9.4% vs 4.7% (无硬刷史) |
| 硬刷者退缩-频率关系 | 刷牙频率越高退缩面显著越多 (无硬刷史者无此关系) |
| 退缩面随年龄 | 每十年约 +3.5 个百分点 (总体 63%) |
| SR: 12 个月 meta | 手动刷者退缩增加大于电动刷 (159 人) |
| SR: 退缩相关刷牙因素 | 频率/横刷法/刷毛硬度/时长/换刷频率 |
| SR: NCCL 相关因素 | 刷法与频率 |
| 3 年 RCT: 电动 vs 手动 | 已有退缩两组均显著减轻, 组间无显著差异 |

## 剂量反应与可执行解读

- 因果方向: SR 结论是"证据仍大体不确定", 但横断面+机制+硬刷剂量效应一致指向机械创伤贡献
- 可执行: 软毛+小幅度水平颤动 (巴氏) 而非横向大力拉锯; 刷 2 分钟不是"刷 2 分钟的力气";
  牙颈部楔状缺损/牙龈线退缩者先自查刷法; 电动牙刷压力感应功能有用
- 平衡点: 力度不足以清菌斑 → 牙龈炎 (T18), 力度过大+方法错 → 退缩与颈部缺损 (本条+T25)

## 证据强度与局限性

- 优势: 有 RCT 端点 (3 年) + 剂量效应横断面
- 局限: 硬刷研究是"历史暴露自报"; SR 自评"证据不确定"; 无退缩进展的预防性 RCT

## 与其他证据的一致性

- 与 T40 同主题的 T25 (NCCL/abfraction) 分工: 本条管"刷", T25 管"酸+力争议"
- 与 T20 (牙线手法) 合并成"技术比工具重要"的通用规律
