# T23. 牙齿稳固的真相: 牙动度由炎症决定, 咬合调整只是辅助

> 层级: [← 总结 README](../README.md) · [维度速览 00-total](../topics/00-total.md) · 本页 `T23`

## 一句话结论

两大队列 (82 人 1,974 牙 8 年; 93 人 2,421 牙 2 年): 初始动度越大的牙对牙周治疗反应越差;
而规范牙周治疗后动度显著下降 (刮治+调合后 1 个月内即改善) — "牙齿变松"的主因是炎症, 不是"缺锻炼"。

## 研究设计与人群

- 设计一: 8 年纵向治疗队列, 82 患者 1,974 牙, 动度 (0-3 级) 与附着变化关联
- 设计二: 治疗过程队列, 93 患者 2,421 牙, 记录刮治/调合/翻瓣/切除各阶段动度变化
- 干预: 刮治+口腔卫生指导+咬合调整+牙周手术, 每 3 个月复诊维护

## 关键数字 (摘自摘要原文)

| 项目 | 数字 |
|---|---|
| 初始动度与治疗反应 | 统计显著相关: 松动的牙袋对治疗反应差 (同严重度下) |
| 初期非手术治疗后 | 动度显著下降 (significant decrease) |
| 袋切除术后 | 动度暂时上升 |
| 2 年后 | 每 3 个月专业清洁者动度进一步下降趋势 |
| 咀嚼偏移研究 (73 人) | 偏离正常咀嚼型式者特定牙动度增加 (Periotest) |

## 剂量反应与可执行解读

- "牙松了要固定/要练"的民间直觉方向反了: 松动的第一治疗是消除炎症 (刮治), 第二才是咬合评估
- 可执行: 发现牙动 → 牙周科就诊, 而不是吃硬物"练牙"或自行买固定器
- 健康牙的生理动度是正常的 (牙周膜弹性), 无需也无法"练稳固"

## 证据强度与局限性

- 优势: 两项大样本治疗队列, 动度作为连续指标反复测量
- 局限: 1980/1982 年研究, 时代标准与今天有差异; 无安慰剂对照

## 与其他证据的一致性

- 与 T22 (咬合创伤不启动牙周炎) 拼合: 松动 = 炎症主犯 + 咬合从犯
- 与 T26 (种植体过载) 形成天然牙/种植牙的对照
