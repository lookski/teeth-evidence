# T36. 失牙与营养: 牙列差 → 膳食纤维/维生素摄入下降, 修复+饮食指导可回补

> 层级: [← 总结 README](../README.md) · [维度速览 00-total](../topics/00-total.md) · 本页 `T36`

## 一句话结论

638 名男性纵向研究: 营养素摄入随牙列恶化递减 (独立于年龄/吸烟/饮酒), 纤维与多数
维生素矿物质摄入与咀嚼功能负相关; 全口义齿 RCT 显示新义齿+简单饮食指导显著提高
蛋白质摄入 — 失牙的营养代价真实存在, 且可干预。

## 研究设计与人群

- 设计一: VA 牙科纵向研究嵌套分析 (638 名男性; 牙数/义齿类型/咀嚼功能 vs 膳食摄入)
- 设计二: 双盲 RCT (62 名完成; 新全口义齿 ± 统一饮食指导小册子; 蛋白摄入为主要终点)
- 设计三: 横断面 (214 名牙周炎患者; IV 期者摄食减少/食物类型改变 + 咀嚼功能客观受损)

## 关键数字 (摘自摘要原文)

| 项目 | 数字 |
|---|---|
| 牙列状态恶化 | 热量校正营养素摄入递减 (独立于年龄/吸烟/酒精) |
| 咀嚼功能 | 纤维与多数维生素/矿物质摄入呈负相关 |
| RCT: 蛋白摄入 | 新义齿+饮食指导组显著高于仅新义齿组 |
| RCT: 咀嚼功能 | 两组 3 个月均较基线显著提升 |
| 牙周炎 IV 期 | 摄食减少/食物类型改变 + 咀嚼功能客观受损 + 生活质量更差 |

## 剂量反应与可执行解读

- 因果链: 失牙/牙周破坏 → 咀嚼效率下降 → 回避高纤维食物 (果蔬全谷) → 营养素摄入下降
- 可执行: 缺牙要修复 (不止是美观/发音); 修复同时给一句饮食指导 (RCT 证明一句提示就有效);
  老人换义齿后主动复查咬合适应
- 与"营养"线合并: 这是口腔健康影响全身健康的直接通路之一 (不经过炎症)

## 证据强度与局限性

- 优势: 纵向 + RCT + 客观咀嚼测量 (双色口香糖混合度) 三角
- 局限: VA 队列全是男性老年人; 横断面部分无法定因果; 膳食自报误差

## 与其他证据的一致性

- 与 T13 (咀嚼-脑血流) 与 T36 本身构成"咀嚼功能-全身"的正反两面: 保留牙列=保留营养
- 与 T17 (2050 无牙负担 +84%) 连接: 失牙负担的下游成本包含营养
