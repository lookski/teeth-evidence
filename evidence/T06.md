# T06. 牙周炎与高血压: 观察 meta (81 项研究)

> 层级: [← 总结 README](../README.md) · [维度速览 00-total](../topics/00-total.md) · 本页 `T06`

## 一句话结论

81 项研究 40 项定量合并: 中重度牙周炎者高血压 OR 1.22 (1.10-1.35), 重度 1.49 (1.09-2.05),
收缩压平均高 4.49 mmHg (2.88-6.11) — 观察"剂量"随牙周炎严重度上升。

## 研究设计与人群

- 设计: 系统综述 + meta 分析 (检索至 2018-12)
- 纳入: 81 项研究入选, 40 项定量合并
- 暴露: 中重度/重度牙周炎 vs 无牙周炎
- 终点: 高血压患病 OR; SBP/DBP 差值; 治疗后血压变化

## 关键数字 (摘自摘要原文)

| 项目 | 数字 |
|---|---|
| 中重度牙周炎 vs 无 | 高血压 OR 1.22 (95% CI 1.10-1.35) |
| 重度牙周炎 vs 无 | OR 1.49 (1.09-2.05) |
| 前瞻研究: PD → 新发高血压 | OR 1.68 (0.85-3.35) (不显著) |
| 收缩压差值 | WMD +4.49 mmHg (2.88-6.11) |
| 舒张压差值 | WMD +2.03 mmHg (1.25-2.81) |
| 12 项干预研究中 | 仅 5 项显示降压, 幅度 SBP 3-12.5 / DBP 0-10 mmHg |

## 剂量反应与可执行解读

- 严重度梯度存在 (1.22 → 1.49), 但前瞻终点不显著 — 观察证据强, 干预证据弱
- 可执行: 高血压患者测血压时, 牙周状况值得问一句; 但"治牙周降压"只有 T04 的小 RCT 支持
- 证据等级: 摘要自评 SORT C (观察性)

## 证据强度与局限性

- 优势: 纳入全面, 连续指标 (mmHg) 与分类指标 (OR) 双重呈现
- 局限: 观察性, 异质性大; 干预研究结论不一致

## 与其他证据的一致性

- 与 T04 (MR+RCT) 互为补充: 观察面 (本条) + 因果面 (T04)
- 与 T03 共识的机制叙述一致
